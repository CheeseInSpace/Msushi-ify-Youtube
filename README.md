# MShushi-ify

Is your browser experience boring? Are you having  
trouble finding engaging click-baity videos?

**Fear no more.**

This extension adds the famous  
youtuber **MSushi** to every thumbnail.

</div>

The extension is awaiting review on FireFox, While Chrome wants me to pay 5$, which isn't worth paying for something made in a couple of minutes. 

In order to add to Chromium based browsers, you'll need to add them using Developer mode. <BR>
For FireFox, See **[This][FireFox Unsigned Addons]**


## Notes

- This extension should be compatible with any Firefox / Chromium based browser.
- This extension was inspired by **[Unnecessary Inventions][UI YouTube]** and his **[Website][UI Website]**.
- This extension is unofficial and not affiliated with MSushi or YouTube.
